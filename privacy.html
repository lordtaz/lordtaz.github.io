JARVIS Privacy Policy

Last updated: 22 November 2026

JARVIS is a private assistant that its owner runs on their own home server for their own use. It has no other users.

What JARVIS accesses

When the owner signs in with Google, JARVIS asks for these permissions:

  • See and download your calendars (calendar.readonly), to show upcoming events.
  • View and edit events on your calendars (calendar.events), to create or update events when the owner asks.

How the data is used and stored

  • Calendar data is used only to provide these features to the owner.
  • The sign-in token and any calendar data are stored only on the owner's own server and devices.
  • Data is not sold, shared with anyone, used for advertising, or used to train AI models.

JARVIS's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from your Google Account permissions page. Removing it stops JARVIS from reading or changing the calendar.

Contact

Questions can be sent to the owner through the GitHub profile that hosts this page.
